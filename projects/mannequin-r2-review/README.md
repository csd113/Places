# Approved mannequin R2 review

Opt-in editable developer preview, outside Cargo tests and CI map baking. Rows one
through four follow the original source manifest order, five clips per row. Every
clip has an explicit loop policy. Door root movement stays baked against a fixed
actor anchor. The fifth row contains the black standing preset and paired door,
chair and tabletop handling sequences; the last row compares .5/1.25 m/s walking
and reference-speed running. `default_neutral` exercises ordinary idle selection.

The carry-walk hand and pickup-floor finger use existing posed glow sockets.
Their nonzero offsets intentionally test the documented socket-wins/fallback
contract. No object attachment, door/lever synchronization, contact-track event
dispatch or runtime IK is implemented. Source alignment/reference data remains
in the complete approved delivery. This fixture does not certify those future
controllers or arbitrary crossfades.

Build explicitly with `places-compile export-project projects/mannequin-r2-review
--out <path>.placesmap --asset-root assets --variants static`. Launch the direct
`places` executable with repository assets and isolated state. The delivered
launcher provides the exact runnable package.

# The Long Way Home

One Explore entry contains Introduction, Below and Homecoming. A Feltling guide,
a two-storey Tall Guest encounter and a physical duck-carrying return lead to the
homecoming. Use the configured movement, crouch, interact and throw bindings.

These are the original authored project, map and Luau files, preserved byte for
byte from the accepted development project. Build or export the complete project
with Static and Full lighting; individual chapter packages omit cross-level
travel. Stable project/member IDs and package version 1.0.0 are retained.

Gameplay checkpoints remain disabled. Campaign completion receipts are separate.
The release acceptance report records exact package and native validation scope.

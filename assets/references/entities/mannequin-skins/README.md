# Shared mannequin appearances

Man, Woman and non-graphic Zombie fitted atlases were produced with the built-in image generation tool using the canonical R2 UV diagnostic. The generated 1254-square images were uniformly resampled to the required 1024-square opaque PNG contract; islands were not repacked. Exact prompts are in `prompts.json`. The model, rig and all 19 clips remain the single accepted GLB.

Runtime PNGs: `assets/entities/mannequin/textures/{man,woman,zombie}-skin.png`. Native moving-model review is recorded in the canonical 0.13.0 release report.

# Places 0.12.0

Published October 19, 2026.

- Introduce the native editor, editable multi-map projects and sandboxed project-local Luau, with protected save/build/play and project recovery.
- Connect nine maps in the Quiet Collection and add separate Closing Time, Beam and Relay Annex campaigns. Expand support for stacked floors, ramps, openings and layered navigation.
- Ship a self-contained macOS arm64 app with the editor, compiler and four project packages. General gameplay saves, Windows/Linux binary acceptance and several reported prop, terrain and lighting defects remained open.

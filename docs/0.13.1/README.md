# Places 0.13.1

Published November 9, 2026.

- Ship separate macOS arm64 and Windows x64 application packages with the game, editor, compiler and live menu. The separate levels download contains Backrooms, the Quiet Collection, all four Beam chapters and The Long Way Home.
- Add The Long Way Home's three-part journey, native Feltling and Tall Guest authoring, reusable live cinematics, and opt-in gameplay checkpoints. Expand Simple-mode construction, add original panic-bar exit doors, and publish an illustrated beginner's guide with a playable example.
- Native acceptance covered macOS/Metal and Windows on development machines. The Mac app requires macOS 27.2 and is ad-hoc signed. Linux and clean-machine installation acceptance remain open.

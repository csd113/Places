# Places 0.7.0

Published September 24, 2026.

- Freeze the last desktop OpenGL/GLES2 baseline. Add Full/Low graphics profiles, several light shapes, baked lightmaps, broader GLB support and selective reflections.
- Add persistent graphics, display and control settings, with correct Retina drawable sizing. Fix light leaks and overlapping decal and doorway surfaces.
- SDL3, wgpu, swimming and the shared interaction system arrive in 0.8.0.

# Places 0.13.0

Published October 28, 2026.

- Ship seven playable projects and editable sources in the Windows portable distribution, with the native player, editor and compiler. Add a live main menu and persistent Quiet Collection favors.
- Add fixed-step movement, shared NPC behavior and prop handoff, articulated ragdolls, visual editor browsers and per-level builds. Improve water, collision, lighting, spatial audio and package reuse.
- Native acceptance covered Windows/DX12 and macOS/Metal. Water-rendering costs and cold input stalls remained. General gameplay checkpoints arrive in 0.13.1, and Relay Annex stays source-only.

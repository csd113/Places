# Places 0.8.0

Published October 4, 2026.

- Move desktop rendering to wgpu/WGSL and windows/input to SDL3. Add offline `.placesmap` preparation with geometry, collision, navigation and baked lighting.
- Add jumping, crouching, ladders, swimming and shared interactions, triggers and entity actions. Expand the outdoor and Halloween content, including Lantern Hollow, and retire the browser editor.
- Native validation covered macOS/Metal. Linux/Vulkan and Windows/DX12 were target backends.

Places Rust 1.99 lint-hardening report — 2026-10-04. Baseline commit:
85b0585fc2185e35e84d6ca0c4e10c019e347a9f. Native validation host: Mac14,9, 12 logical
CPUs, 16 GiB, Metal. No commits were created. Dependencies, Cargo.lock, authored map
contents, lighting calibration, movement tuning, controls and bundled .placesmap files
remain unchanged.

Policy: Cargo.toml owns the enforcement. Rust warnings, future_incompatible,
unused_results and unsafe_op_in_unsafe_fn are denied. Clippy all, pedantic, nursery and
cargo are denied. All 30 existing Clippy entries are retained; 24 entries are new or
strengthened. rust-toolchain.toml already pinned Rust 1.99.0 and remains unchanged.
policy.json contains every exact level and priority, plus the original keys.

The explicitly enforced restrictions are: unwrap_used, expect_used, panic, todo,
unimplemented, indexing_slicing, string_slice, default_numeric_fallback,
lossy_float_literal, as_conversions, arithmetic_side_effects, undocumented_unsafe_blocks,
multiple_unsafe_ops_per_block, allow_attributes_without_reason, iter_over_hash_type,
let_underscore_must_use, map_err_ignore, rest_pattern_accessible_field,
wildcard_enum_match_arm, shadow_unrelated, shadow_reuse, shadow_same,
missing_assert_message, large_stack_arrays, large_stack_frames and large_enum_variant.
Useful existing cast, float-comparison, ownership, documentation, logging and process-
control lints remain active; denied warnings enforce their warning-level settings. None of
the objective’s prohibited noisy global restriction lints was added.

Permanent gate: tools/check-rust.sh runs formatting, locked check, Clippy in both
development and release modes, and locked all-feature workspace tests. tools/verify.sh
calls the same gate. .github/workflows/rust.yml runs it on macOS for pushes, pull requests
and manual dispatch, installs SDL3/pkg-config and selects the pinned toolchain. Release-
mode linting catches cfg(not(debug_assertions)) code as well. clippy.toml’s existing
exceptions for unavoidable transitive hashbrown/miniz_oxide/syn version splits are
unchanged.

Diagnostics: the first expanded run emitted 6,881 diagnostics, representing 4,905 unique
findings. Compilation stopped in the library, so this initial count excludes later binary
findings. The final expanded all-target/all-feature run has zero diagnostics. Auditing old
numeric exceptions exposed additional findings, including 114 cast diagnostics and 43
arithmetic expressions; they were reviewed rather than concealed by restoring broad
exceptions.

Correctness and crash resilience: the macOS CPU sampler now releases each mach_host_self
send-right reference on success and failure, validates the four-counter ABI count and
reports release errors. An isolated native integration test confirms 64 samples do not
increase the port reference count. Both entry points reject non-Unicode OS arguments with
normal error statuses before startup or filesystem work; a subprocess test covers both
executables, with Unix-byte and Windows-surrogate fixtures.

Material JSON bounds are checked in f64 before narrowing: values just above a declared
maximum can no longer round into an accepted f32 endpoint. Non-finite material and GPU-
utilization values are rejected, and utilization ratios are capped before percentage
multiplication can overflow. Reflection plane IDs use checked u16 conversion; exhausting
the ID space no longer aliases unrelated planes. Huge navigation radii are bounded by the
actual grid instead of permitting billions of empty rings.

Numeric and indexing work: entity/component access, grid dimensions and flattened
addresses, collection-to-GPU lengths, mesh indices and file/texture sizing now use checked
conversions or explicit bounded invariants. RGBA sizing widens before multiplication and
checks the platform collection size. Probe lookup computes one checked address instead of
duplicating flattening. Route interpolation rejects non-finite or excessive sample counts
before iteration; a zero-cell lighting axis returns its origin rather than dividing by
zero. Existing valid floating-point operation order and exact sentinel comparisons are
preserved. Test conversion helpers validate the exact integer ranges of f32 and f64.

Filesystem, errors and workers: package publication exclusively creates its owned sibling
temporary, flushes/syncs it before rename and never follows or deletes another owner’s
stale file or symlink. Failure preserves the original error and any cleanup error. CSV
creation, writes and flushes, device polling, logging, worker joins and texture
preparation now handle meaningful failures explicitly. Texture worker spawn/panic failures
leave retriable slots and use serial fallback. Ownership drops and intentionally ignored
copy statuses were distinguished; error context replaces erased map_err payloads.

Unsafe operations are individually scoped and describe ABI, pointer validity,
window/surface lifetime or the compiler’s pre-thread environment setup. Tests inject
benchmark configuration directly instead of mutating process environment concurrently. No
unsafe shortcut was introduced to satisfy a lint. Existing stack and enum layouts were
kept where diagnostics did not identify a risk; BVH bin counts now use the validated u32
scene bound, reducing each bin from 32 to 28 bytes on this host.

Determinism and hot paths: geometry grouping uses ordered keys; loader face and
fixture/catalog processing establishes order before output or accumulation. The one
retained hash-iteration exception only counts independent integer statistics. No per-frame
sorting, lock, dynamic dispatch or extra GPU synchronization was added. Navigation ring
traversal no longer allocates a Vec for each ring. Fixed model lists use arrays, probe
address checks are not repeated, and BVH split iteration avoids an index-plus-one lookup.
Stage-specific names and explicit enum fields make state transitions and numeric stages
reviewable.

Texture policy: four fixed legacy images are now real PNGs: assets/core/ui/font_01.png;
assets/core/decals/validation_atlas_01.png; assets/core/textures/missing_01.png;
assets/core/textures/white_fallback_01.png. They preserve every original decoded RGBA
byte, aspect ratio, UV layout, alpha value and row orientation, including the decal’s
historical bottom-up convention. The catalogue and canonical specifications describe their
contracts. Old public atlas accessor names remain compatible and decode these immutable
resources. Tests pin complete pixel hashes and dimensions. No artwork was redrawn.

Exceptions: the original source had 424 allow attributes without reasons. The final source
has 426 attributes: 110 allow and 316 expect, all with meaningful reasons. This net count
does not mean only two new sites: old exceptions were removed, narrowed or converted to
checked expectations. A first audited pass removed 57 obsolete entries; later passes
removed further obsolete atlas, float and fixture exceptions. Cast exceptions were removed
from 37 broad scopes, and production arithmetic exceptions from eight modules. Arithmetic
entries fell from 137 to 102 and precision-cast entries from 75 to 55. Every retained and
new site, lint and justification is listed in exceptions.jsonl with its current source
line.

New exception families are confined to intentional floating-point vector operations,
checked/clamped native float casts, constant GPU layout conversions unavailable through
const TryFrom, and demonstrated bounded integer operations. Test setup and independent
numeric oracles remain confined to test scopes. The one new production expect call is for
the closed set of four immutable embedded PNGs; complete pixel tests validate them, and
external images use fallible decoder paths. Blanket crate-wide suppression of the
requested policy was not added.

Validation: cargo fmt --all --check; cargo check --locked --workspace --all-targets --all-
features; Clippy with every requested -D flag; release Clippy under the identical Cargo
policy; cargo test --locked --workspace --all-features; cargo build --locked --release
--bins; and git diff --check all pass. The final ordinary Rust suite passed 1995 tests,
with 23 opt-in diagnostics ignored. The ignored atlas-plan test and both Low-lighting
resource tests were run explicitly and passed. Full exact commands, logs and exit codes
are in validation.json.

Additional validation passed: catalogue (250 assets, 134 placeable, four themes, zero
warnings); prop, texture and asset inventory checks; Halloween assets and clip seams;
outdoor, night-route, Hollow, lighting-quality and Model Zoo generator checks; all
package, packaging, GLB-accessor, asset-audit, execution, benchmark-harness and geometry-
repair Python suites. The compiled-build suite passed 10 tests and wgpu bootstrap passed
26, using real SDL windows and Metal. Existing 39 texture soft-budget warnings are
understood shipped artwork; they are not Rust warnings or new failures.

Representative maps were clean-built with 12 workers and off/medium/full variants:
tests/fixtures/levels/test_room.json, assets/levels/places_demo.json, preserved The Pit
source at debug-maps/movement-audit-20261003/sources/level0_pit.json, and
assets/levels/lantern_hollow.json. Every non-manifest record matches the baseline byte for
byte, including geometry, collision, navigation, semantics, props, HDR lightmaps,
irradiance and mips. Only catalogue-based manifest input fingerprints differ. All four new
packages pass validate and verify --require-current. Native load traces prove those
precise package identities were used with no runtime bake.

All 27 final native image comparisons (54 captures, nine views at Low/Medium/High,
including the pause-menu font) have identical pixels. Twelve real-time before/after
movement cases cover walking, stair ascent/descent, crouching under a header, head
collision, an interactive doorway, a solid prop, pool entry/surfacing/exit, unsupported

time sampling differs between runs. Deterministic controller/collision regressions also
pass in the ordinary suite.

Compiler resident-memory check: the first samples showed higher candidate peak RSS, so
places_demo was repeated sequentially with the final and baseline binaries, the same
current asset tree, 12 workers and no other Places jobs. Peak RSS was 3.18 GiB baseline
and 2.58 GiB candidate; wall time was 169.097 s and 171.064 s. The paired candidate time
differs by +1.16%, with nearly equal CPU time; no meaningful compiler regression was
observed. Both repeat payload comparisons pass. The candidate's first 4.24 GiB peak was
not reproduced. Resident-memory figures vary with host conditions; these limited samples
do not establish a persistent memory change.

Caveats: hosted GitHub CI was configured but cannot be exercised without a push;
Linux/Vulkan and Windows/DX12 were not run on this host. To honor the no-unnecessary-
rebake constraint, existing bundled packages were not rewritten. Their developer
--require-current fingerprints are stale after the catalogue additions, although their
unchanged physical payloads load and render. Newly built validation packages are current.
The desktop gate was run against those scratch packages rather than letting
tools/verify.sh rewrite the four bundled archives. No claimed lint remains failing.

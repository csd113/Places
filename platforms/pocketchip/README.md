# PocketCHIP support

This directory isolates the historical PocketCHIP/Vitrallis deployment
artifacts from the platform-neutral Places game source at the repository root.

`vitrallis/` contains the legacy manifest and precompiled ARMv7 payload. It is
kept for reference while a future PocketCHIP adaptation establishes an updated
build and release workflow. It is not used by the macOS development build.

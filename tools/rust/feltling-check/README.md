# Feltling native CPU lifecycle probe

Set `PLACES_ASSET_ROOT` to the repository assets directory and run
`places-feltling-check <new-report.json>`. This explicit developer operation
loads the real 925 KB model and one tiny CPU world. It protects importer/pose
ownership, interrupted one-shot reconstruction and completion bindings, derived
status checkpoints, disabled audio retirement and post-despawn membership rules.
It costs under a second after compilation and creates no map, window or device.
GPU appearance, movement contacts, device output and performance require separate
native game evidence. It is outside ordinary Rust tests and CI; those retain the
small pure policy/boundary regressions without an installed runtime payload.

# Prop asset toolkit

Development-only tooling that generates the shipped prop assets. Blender is not
part of this toolchain, so the pack is built from primitives in pure Python
(stdlib only) and packed into self-contained GLBs.

The asset rules — registry format, coordinate/scale/origin convention, triangle
and texture budgets, GLB profile — are documented once in
[`../../assets/props/README.md`](../../assets/props/README.md). Read that first.

## Layout

| file                  | purpose                                                            |
| --------------------- | ------------------------------------------------------------------ |
| `build.py`            | builds every prop in the catalogue, validates, writes `prop_proxies.json`, prints a budget report |
| `preview.py`          | software rasteriser: per-prop previews, contact sheets, editor thumbnails |
| `glb.py`              | minimal GLB writer/reader (the one format the game loader accepts)  |
| `mesh.py`             | `Mesh` + `PropBuilder`: boxes, low-segment cylinders, tubes, quads  |
| `tex.py`              | procedural texture painter (fills, grain, wear, panels, labels)     |
| `palette.py`          | the shared, deliberately muted colour palette                       |
| `parts/furniture.py`  | couch, armchair, chair, table, desk, bookshelf, cabinet, bed        |
| `parts/appliances.py` | stove, sink, fridge, washing machine, vending machine, water cooler |
| `parts/utility.py`    | crate (the commented exemplar), cardboard box                       |
| `parts/decor.py`      | plant, rug, lamp, TV                                                |

## Commands

```sh
cd apps/liminal-rust
python3 tools/props/build.py                     # rebuild + validate every prop
python3 tools/props/build.py --only core:chair   # iterate on one prop
python3 tools/props/build.py --check             # validate shipped GLBs only
python3 tools/props/build.py --report            # budget table only
python3 tools/props/build.py --thumbs            # refresh editor thumbnails
python3 tools/props/preview.py --all             # per-prop preview renders
python3 tools/props/preview.py --sheet           # contact sheets for style review
python3 tools/props/preview.py --only core:chair --out target/prop-previews
```

Previews and thumbnails are written to `target/prop-previews/` (gitignored);
`level-editor/assets/thumbs/*.png` is the only generated preview that ships, and
the prop browser falls back to its colour swatch when a thumbnail is missing.

The demo levels that exercise the pack are generated by
`tools/levels/build_demo_levels.py` (`asset_demo.json` and
`asset_maintained.json` in `levels/`, plus `prop_showcase.json` and
`prop_stress.json` in `assets/levels/`); see `assets/props/README.md` for the
run flags that boot straight into them and capture a frame.

## Writing a prop

```python
def build_chair(p: PropBuilder) -> None:
    size = p.size                       # catalogue [w, h, d] in metres
    tex = p.set_texture(64, seed=31)    # 64 or 128; must be called before painting
    tex.auto("wood", "fabric")          # named UV regions (here: two cells)

    wood = palette.hex_to_rgb(palette.WOOD_MID)
    tex.fill("wood", wood, jitter=8)
    tex.grain("wood", palette.hex_to_rgb(palette.WOOD_DARK), density=0.4, alpha=60)

    seat = tex.uv("fabric")
    p.box((0.0, 0.45, 0.0), (0.46, 0.05, 0.46), uv=seat, color=palette.hex_to_rgb(palette.FABRIC_BEIGE))
    for sx in (-1.0, 1.0):
        for sz in (-1.0, 1.0):
            p.cylinder((sx * 0.2, 0.0, sz * 0.2), 0.02, 0.45, segments=6,
                       uv=tex.uv("wood"), color=wood)


PROPS = {"core:chair": build_chair}
```

Rules the builder enforces for you: metrics are metres, `+Z` is the front, the
mesh must be horizontally centred with its base at `y = 0`, UVs stay inside
`0..1`, no NaNs, no zero-area triangles, and the bounding box must match the
catalogue `size`. `build.py` additionally enforces the triangle/texture budgets
and the "no external files" GLB profile.

Keep proportions and colour choices consistent with the rest of the pack: this
is a muted, faded, slightly worn PS2-era institutional/domestic set, not a
modern showroom. Favour silhouette and large colour blocks; spend texture
pixels on handles, doors, burners, screens and wear, never on tiny detail that
vanishes on a 480×272 screen.

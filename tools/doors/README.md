# Exit-door source owner

See [the canonical contract](../../docs/EXIT_DOORS.md). `check.py --check` is
read-only and checks committed Blender/GIMP/PNG/GLB identities plus runtime
preset structure. It does not run Blender, paint textures, bake a map or certify
native appearance. `source/` is editable original artwork, not build output.

`PREPARATION.md` and `metadata/provenance.json` describe the historical private
preparation phase. `CORRECTION.md` and `metadata/integration_correction.json`
record the later Blender hinge correction discovered by the actual engine gate.
Current export/source identities are in `metadata/artifact_identities.json` and
`asset_gate_report.json`. The initial ZIP remains preserved outside the checkout;
it is not the current accepted export. Native evidence belongs to the dated
integration report, not a Blender-render certificate.

`acceptance.py --out <fresh-private-dir>` creates a tiny one-room, fitted-door
project for explicit native checks. It does not build or install a shipped map.
See the dated native report for export and launch recipes.
